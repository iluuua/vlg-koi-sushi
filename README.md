# Кои суши — сайт-визитка

Одностраничный сайт суши-бара **«Кои суши»** (KOI SUSHI), Волгоград,
бульвар 30-летия Победы, 58А (район Семь Ветров).

- **Живая ссылка:** https://iluuua.github.io/vlg-koi-sushi/
- **Карточка в Яндекс Картах:** https://yandex.ru/maps/org/koi_sushi/13250794374/
- Сборка: `python3 ../_vlg-sitekit/build.py vlg-koi-sushi`
- Проверка: `python3 ../_vlg-sitekit/check.py vlg-koi-sushi koi-sushi` → `ok: true`

## Откуда данные

| Что | Источник |
|---|---|
| Адрес, часы, телефоны, рейтинг, аспекты, отзывы, фото | Карточка Яндекс Карт, срез в `_vlg-sitekit/data/koi-sushi.json` (август 2026) |
| Логотип | Логотип из карточки Яндекс Карт |
| Фото героя и галереи | 8 фотографий из галереи карточки Яндекс Карт, кадрированы `imgtool.py` |
| Названия роллов, сета «Майами Уинслоу», кукси, адрес самовывоза, ссылки на VK/приложение | Официальный телеграм-канал заведения [@koisushi_vlg](https://t.me/koisushi_vlg) |
| Названия сетов «Сакура», «Флагман», «Party», блюда (том ям, вок, мидии запечённые, гунканы, сырные палочки, фри) | Отзывы гостей в карточке Яндекс Карт |
| Утверждение «риса и начинки поровну, ~40 г лосося в ролл» | Ответ заведения на отзыв в Яндекс Картах (поле `reply` в данных) |

Проценты в блоке «Самые обсуждаемые темы» посчитаны как
`round(100 * positive / (positive + negative))` по полю `aspects` — так же,
как их показывает Яндекс: Еда 91%, Роллы и суши 89%, Персонал 78%,
Время ожидания 76%, Доставка 80%, Атмосфера 100%.

## Открытые вопросы к владельцу

1. **Цен на сайте нет — и это главное, что стоит исправить.**
   Прайс заведения не опубликован нигде в открытом доступе: в карточке
   Яндекс Карт раздела «Меню» нет, среди 43 фотографий карточки нет ни одного
   снимка меню или прайса, домен из карточки
   (`piokok.com/id/profile/koi.vlg`, зеркало Instagram) отдаёт 403.
   Поэтому в разделе «Меню» стоят только названия позиций с пометкой
   «уточняйте при заказе». **Пришлите прайс (файл, фото или выгрузку из
   приложения) — цены и граммовки добавим на страницу.**
2. **Полнота меню.** Сейчас на странице 29 позиций в 4 разделах — всё, что
   удалось подтвердить по официальным публикациям и отзывам. Разделы напитков,
   поке/боулов, детского меню и соусов не показаны, потому что подтверждений
   не нашлось. Список наверняка неполный.
3. **Второй адрес.** В телеграм-канале заведение указывает вторую точку
   самовывоза — ул. Рабоче-Крестьянская, 11, и отдельный телефон
   51-51-67 (Ворошиловский район). На сайте показан только адрес 58А
   и телефоны из карточки Яндекс Карт. Нужно ли добавить второй филиал?
4. **Соцсети.** В карточке Яндекс Карт в качестве сайта указано зеркало
   Instagram. На сайте вместо него стоят каналы, которые заведение само
   называет в своих публикациях: Telegram, группа ВКонтакте
   (`vk.com/club221151999`), WhatsApp +7 (937) 727-72-58 и приложение
   «Кои Суши» в App Store и Google Play. Если есть свой домен — пришлите.
5. **Акции.** Промокоды из телеграм-канала одноразовые и просрочены
   (действовали по одному-два дня), поэтому блока с акциями на странице нет.
   Если есть постоянная акция (например, скидка на самовывоз или бонусная
   программа в приложении) — добавим отдельным блоком.
6. **Отзывы.** Показаны 6 реальных отзывов из 119: пять на 5 звёзд и один
   сдержанный на 4 звезды. Опечатки исправлены, длинные отзывы сокращены,
   смысл не менялся. У заведения есть и низкие оценки — если хотите,
   можно поменять состав подборки.

## Структура

```
content.json      — весь текст и данные страницы (единственный файл для правок)
index.html        — генерируется build.py, вручную не править
styles.css        — копируется из кита
script.js         — копируется из кита
robots.txt        — генерируется build.py
sitemap.xml       — генерируется build.py
img/              — hero.jpg, g1..g8.jpg, logo.jpg, favicon.png
img/raw/          — исходники фото, в git не попадают (.gitignore)
```

После правки `content.json` нужно пересобрать сайт (`build.py`) и заново
прогнать `check.py`.
